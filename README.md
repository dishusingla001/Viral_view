# Marketing Website

A modern, professional marketing website built with React and Tailwind CSS. Features a clean, minimal design with smooth animations and full responsive support.

## 🚀 Features

- **Modern Tech Stack**: React 18 + Vite + Tailwind CSS
- **Fully Responsive**: Optimized for mobile, tablet, and desktop
- **Smooth Animations**: Scroll animations, hover effects, and transitions
- **Clean Design**: Minimal, professional aesthetic with custom color palette
- **Reusable Components**: Modular architecture for easy customization
- **Static Site**: No backend required, ready for Netlify/Vercel deployment

## 📦 Installation

1. Install dependencies:
```bash
npm install
```

2. Start the development server:
```bash
npm run dev
```

3. Build for production:
```bash
npm run build
```

4. Preview production build:
```bash
npm run preview
```

## 🎨 Customization

### Colors
Edit `tailwind.config.js` to customize the color palette:
- `primary`: Main brand color (currently blue)
- `accent`: Secondary accent color (currently yellow/orange)

### Content
Replace placeholder content in each component:
- **Navbar.jsx**: Update brand name and navigation links
- **Hero.jsx**: Change headline, stats, and hero image
- **About.jsx**: Add your bio and expertise
- **Services.jsx**: Customize service offerings
- **Portfolio.jsx**: Add your real projects
- **Testimonials.jsx**: Include client testimonials
- **Contact.jsx**: Update contact information
- **Footer.jsx**: Modify footer links and social media

### Images
Replace emoji placeholders with actual images:
- Hero section: Add professional marketing visuals
- About section: Add your professional photo
- Portfolio section: Add project screenshots/mockups

## 📱 Sections

1. **Navbar** - Sticky navigation with mobile menu
2. **Hero** - Eye-catching intro with CTAs
3. **About** - Personal bio and expertise
4. **Services** - Marketing services offered
5. **Portfolio** - Project showcase
6. **Testimonials** - Client reviews
7. **Process** - How you work
8. **Contact** - Contact form and info
9. **Footer** - Site links and social media

## 🌐 Deployment

### Netlify
```bash
npm run build
# Drag and drop the 'dist' folder to Netlify
```

### Vercel
```bash
npm run build
vercel --prod
```
